# Negative Keywords — `Plumbing_Master_Negs` (ONE shared list, all 8 campaigns)

A single **shared negative keyword list**, built once, applied to all 8 city campaigns. ~375 negatives to start — a **living list** (keep appending from the weekly Search Terms report; Google allows 10,000 per list).

**Strategy:** pay-per-call — we're only paid on *qualified 60s+ calls*. So we ruthlessly block research, DIY, jobs, shopping, "free/cheap" tire-kickers, other trades, and entertainment.

## How to add it (Google Ads) — one copy/paste
1. **Tools → Shared library → Negative keyword lists → +** → name it `Plumbing_Master_Negs`.
2. **Copy the entire MASTER PASTE BLOCK below and paste it in.** Match types are already embedded — nothing else to set.
3. **Apply to campaigns →** tick all 8. Done.
4. Weekly: open Search Terms → append new junk here.

## Match-type syntax (already applied for you)
- `"two words"` = **PHRASE** — blocks queries containing that exact phrase.
- `word` (no quotes) = **BROAD** — blocks any query containing that word.
- `[word]` = **EXACT** — blocks only that exact query. *(none needed here)*
- ⚠️ Negatives don't match plurals/variants, so both forms are listed (`cost`/`costs`).

## ⛔ DO NOT block these (they ARE intent / in our copy)
| Kept out | Why |
|----------|-----|
| `supply` (bare) | Meaningful in real intent — **"water supply line repair"**, "supply line leak". Only the shopping sense is blocked (`supplies`, `supplier`, `supplyhouse`, `"pex supply"`). |
| `hire` | "hire a plumber" = high intent. |
| `affordable` | We bid "affordable plumber" (Garden Grove). |
| `best` | We bid "best plumber near me". |
| `commercial` | We bid "commercial plumber". |
| `lead` (singular) | "lead pipe replacement" = real job. Only `leads` (marketing) blocked. |
| `heater` | We bid "water heater". (`heating` IS blocked.) |
| `licensed`, `near me`, `same day`, `emergency`, `open now`, `24 hour`, `repair`, `install`, `replacement`, `service`, `faucet`, `valve`, `pipe`, `fixture`, `slab`, `leak`, `drain`, `sewer`, `repipe`, `softener`, `tankless`, `water line` | Core services/keywords. |
| any **city name** | Geo-targeting handles location. |

> **Blocked on purpose** (not pay-per-call intent): `free` · `test` · `union` · `grant` · `certification`.
