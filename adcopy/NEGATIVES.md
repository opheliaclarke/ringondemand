# Negative Keywords — `Plumbing_Master_Negs` (shared across all 8 campaigns)

One **shared negative keyword list** attached to every city campaign. Build once, attach everywhere. This kills the junk (jobs, DIY/how-to, retail, free/cheap, other trades, games, brand/research, homonyms) so budget only buys real "I-need-a-plumber-now" calls.

**Why a shared list:** the junk above is identical in every city — no reason to maintain it 8×. (City-specific geo negatives stay per-campaign — see the bottom.)

## How to add it (Google Ads)
1. **Tools → Shared library → Negative keyword lists → +** → name it `Plumbing_Master_Negs`.
2. Paste the **copy-paste block** at the bottom (it already includes match-type syntax).
3. **Apply to campaigns →** tick all 8.
4. Done. Re-check the Search Terms report weekly and add new junk here.

## Match-type syntax used below
- `word` = **broad** negative — blocks any query containing that word (use for unambiguous junk like `job`, `diy`, `free`).
- `"two words"` = **phrase** negative — blocks that phrase in order (use for `"hot rod"`, brand names).
- `[exact]` = **exact** negative — blocks only that exact query (rarely needed here).

## 🗺️ Geo negatives — keep these PER-CAMPAIGN (not in the shared list)
The shared list can't hold city-specific blocks. In **each** campaign, add the neighboring cities you don't service as **phrase** negatives so out-of-area searches (like `"marvelous plumbing buena park"` that leaked into Garden Grove) don't trigger. Example starters:
- **Garden Grove** → `"buena park"`, `"anaheim"`, `"santa ana"`, `"westminster"`, `"stanton"`
- **Torrance** → `"long beach"`, `"carson"`, `"gardena"`, `"redondo beach"`, `"lomita"`
- **Fullerton** → `"anaheim"`, `"brea"`, `"placentia"`, `"la habra"`, `"buena park"`
- (repeat the pattern for the rest — neighbors you don't cover.)
> This is the *one* exception to "campaign-level only, no ad-group" — geo negatives can't be shared because they differ by city.
