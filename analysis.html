Updated Jun 19. Goal = more calls, ordered by impact. (Read-only analysis; changes made manually in the account.)

✅ THE change — switch all 7 to Target CPA $90 (decided Jun 19)

What: move all 7 campaigns off plain Maximize Conversions onto Target CPA = $90 (just under the ~$100 call payout). Best applied as one portfolio Target CPA strategy across all 7 — it pools the thin conversion data into a single learning set instead of 7 starved ones.

Why: 50–75% of searches never see our ad because one ~$196 click drains the day's budget. A $90 CPA cap stops that → budget spreads across the day → more calls at the same spend. (Littleton's $196 click did convert, so the goal isn't killing expensive clicks — it's not going dark for the rest of the day.)

No max-CPC limit: only a portfolio tCPA even allows one, and Google's guidance is that bid limits hurt Smart Bidding. The $90 target already stops $196 clicks by design (it won't overpay per click unless a conversion is near-certain). Add a ~$40 max-CPC cap only later, if absurd clicks somehow persist past 1–2 weeks.

Heads-up: this resets learning on all 7, and at $90 (vs the ~$200–500 it's been paying per call) delivery may go quiet for a few days while it learns to find cheaper calls. Give it 1–2 weeks. If it flatlines entirely, nudge to $99, or start at ~$120 and ratchet down. Watch Ringba converted, not Google's lagging count. Flat $90 is fine — RTB upside ($140–$240 calls) covers the lower-payout cities.

5. What to change — revised

Current stance: hold and observe. Maximize Conversions stays (it's what started producing calls), budgets stay put, and Jun 18 already shows 2 calls vs 0 the day before — early signs of improvement. The items below are standing options, not changes to rush.

Priority 1 — Conversion tracking (owned by Leo's Ringba team)

The biggest lever is getting Google to see the qualified calls Ringba already logs (~2/day). The gclid → Ringba → Google offline-upload pipeline sits with Leo's team and is being worked on; nothing actionable on our side right now. Once Google sees real conversions, smart bidding rationalizes on its own.

Priority 2 — Add a Target CPA to Maximize Conversions

Set a Target CPA around $100–130 on the existing strategy. This keeps conversion-based bidding on the high-intent terms but tells Google not to chase a $196 click (which implies a CPA far above target). It's the cap that stops the bleed without killing reach. If volume throttles too hard after ~1 week, raise the target.

Priority 3 — Budget (holding steady, by decision)

Budgets are being left untouched while the campaigns settle — no changes for now. Kept here only as reference for when/if revisited: per-campaign budgets don't cap the total, and Max-Conversions can spend 2× on any day. If a true cap is ever wanted:

  • One shared budget of $500/day across all 7 campaigns (Tools → Shared library → Budgets → +). Caps the monthly average at ~$500/day (~$15.2k/mo); single days can still flex to ~2×, averaging out.
  • For a hard daily ceiling (no day over $500): set the shared budget to $250/day — the 2× rule then tops out at ~$500. Lower volume, but a true cap.
  • Trade-off: a shared budget lets Google shift spend to the best performers but removes per-city control.

Priority 4 — Tighten match types

Set the proven call-drivers (e.g. plumbers near me, plumber [city]) to phrase/exact so the budget isn't spent on loose broad matches at top dollar.
